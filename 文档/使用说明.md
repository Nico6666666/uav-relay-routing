# 使用说明

> 本文件只回答：**怎么跑、结果在哪、怎么加速、出问题怎么办。**
> 结构说明见 [`代码结构.md`](代码结构.md)；图件生成见 [`绘图说明.md`](绘图说明.md)。

---

## 1. 环境

- Python 3.11（3.9+ 可用）
- `numpy >= 2`
- `scipy >= 1.15`（读 `.mat` DEM、求根）
- `matplotlib >= 3.10`（出图）

安装：

```bash
pip install -r requirements.txt
```

不需要 `pandas` / `openpyxl`：数据文件已提供 JSON。

---

## 2. 快速开始

在仓库根目录下：

```bash
python 运行入口.py 最大安全载荷
python 运行入口.py 可行组批
python 运行入口.py 精确前沿
python 运行入口.py 余量灵敏度

python 运行入口.py 多目标优化
python 运行入口.py 运输方案检验

python 运行入口.py 联合调度 --规模 快速
python 运行入口.py 联合方案检验

python 运行入口.py 分区配置
python 运行入口.py 资源缺口
```

也可以直接运行某个主程序：

```bash
python "源代码/求解器/联合调度与中继/五目标优化/主程序.py" --规模 快速
```

---

## 3. 推荐流程

1. **单点往返与组批**：`最大安全载荷` → `可行组批` → `精确前沿` → `余量灵敏度`
2. **多点多架次调度**：`多目标优化` → `运输方案检验`
3. **联合调度与中继（论文主线）**：
   - 先预热缓存：`python 运行入口.py 预热缓存`
   - 再跑正式规模：`python 运行入口.py 联合调度 --规模 标准`
   - 最后检验：`python 运行入口.py 联合方案检验`
4. **分区与资源核算**：`分区配置` → `资源缺口`

> 顺序不能颠倒：下游读取上游的 `输出/*.json`，缺失会明确报错。

## 4. 规模档位

`联合调度` 的规模档位在
`源代码/求解器/联合调度与中继/五目标优化/主程序.py` 的 `规模表` 中定义：

| 档位 | 种群 × 代数 × 步长数 | 用途 |
|---|---|---|
| `试跑` | 6 × 1 × 2 | 冒烟测试，只验证流程 |
| `快速` | 24 × 4 × 3 | 日常调试，约 6 分钟（冷缓存） |
| `标准` | 60 × 24 × 7 | 论文结果档位 |
| `全量` | 120 × 200 × 7 | 算力需求极大，不建议本机跑 |

规模只影响墙钟，不改变任何物理/通信口径。

## 5. 加速：先预热缓存

首次运行 `标准` 档时，冷评估约 **85 s/次**，热评估约 **0.65 s/次**。
中继站解缓存按「悬停点 × 缺口位姿」记忆，跨运行有效。

推荐两步：

```bash
# 第一步：广度优先、深度很浅，把缓存填满（约 10–20 分钟，视机器）
python 运行入口.py 预热缓存

# 第二步：正式运行，自动加载缓存
python 运行入口.py 联合调度 --规模 标准
```

实测（本机 24 逻辑核 / 8 进程）：

| 场景 | 墙钟 |
|---|---|
| `快速` 冷缓存 | 约 390 s |
| `快速` 热缓存 | 约 179 s |

标准档的冷/热差异更大；预热通常能把总时间显著压低。

### 其他加速手段

- `--进程数 auto`（默认）自动探测硬件；`--进程数 N` 显式覆盖。
- `--自检串行` 跳过并行一致性自检，省约 1 分钟；**交付前保持默认开启**。
- `--复用步长` 是**近似**提速（约 7×），结果与精确档不同，仅建议全量档探索用。
- 绘图已设置 `svg.fonttype='none'`，避免 matplotlib 把文字转路径导致的缓慢排版。

## 7. 自检与复现

- 每个主程序都会执行自检，并在控制台、`*.md`、`*.json` 三处同时落盘。
- 自检不通过会抛 `RuntimeError`，不会静默给出错误结果。
- 唯一随机源是固定种子；同一输入应得到同一输出。
- 并行与串行结果逐位一致（`联合调度` 默认自检）。

## 8. 常见问题

**Q：运行报 `ModuleNotFoundError: No module named '源代码'`？**
A：主程序需要把项目根加入 `sys.path`。直接运行主程序时已内置引导；若在别处 import，请先
`sys.path.insert(0, "仓库根目录")`，或从仓库根目录运行。

**Q：多进程报 `if __name__ == "__main__"` 保护错误？**
A：Windows 使用 spawn，入口脚本必须带主模块保护。`运行入口.py` 与各主程序都已带。

**Q：图里中文变方框？**
A：需要安装 `Microsoft YaHei` / `SimHei` / `SimSun` 之一；论文阶段会重绘为英文图。

**Q：标准档跑了很久还没结束？**
A：先确认是否加载了缓存；首次冷缓存慢是正常的。建议先跑 `预热缓存`。

**Q：`全量` 档内存暴涨？**
A：标准库 Python 在 Windows 上不会把已释放的堆还给系统；代码已通过回收 worker 进程控制。
不要随意增大进程数。
