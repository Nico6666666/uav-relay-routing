# 论文图件说明（中文 / 英文双语）

> 目标：同一份数据、同一套绘图代码，生成中文图与英文图。
> 中文图用于中文稿审阅；英文图用于最终 Mathematics 投稿。

---

## 1. 生成命令

在仓库根目录下：

```bash
# 只生成中文图
python 工具/绘图/生成论文图.py --语言 中文

# 只生成英文图
python 工具/绘图/生成论文图.py --语言 English

# 一次生成两套
python 工具/绘图/生成论文图.py --语言 all
```

## 3. 字体与格式

| 项 | 中文 | 英文 |
|---|---|---|
| 字体 | Microsoft YaHei / SimHei / SimSun | DejaVu Sans |
| 负号 | `axes.unicode_minus=False` | 默认 |
| SVG | `svg.fonttype='none'`，文字可编辑 | 同左 |
| PNG | 300 dpi | 300 dpi（最终可重出 600 dpi） |
| 文件命名 | `图NN_中文名` | `FigNN_English_Name` |

---

## 4. 术语表

所有图内文字从 `工具/绘图/术语表.py` 取，键值同时含 `zh` 与 `en`。

新增图或改标签时，只改术语表，不写死在绘图函数里。

---

## 5. 图件清单

`结果/论文图/图件清单.csv` 记录：

- 语言；
- 图号；
- 文件相对路径；
- 字节数；
- SHA-256；
- 数据源；
- 生成命令。

用途：论文中每张图都能追溯到数据源与生成命令；中英文图可用哈希确认“同数据、不同语言”。

## 7. 在文稿中使用

- 中文稿：引用 `结果/论文图/中文/...`；
- 英文稿：引用 `结果/论文图/英文/...`；
- 不要在中文稿中放英文图，也不要在英文稿中放中文图；
- 图号必须与正文引用一致（图 1–9 / Fig. 1–9）。
