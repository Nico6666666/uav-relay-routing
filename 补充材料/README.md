## 说明

1. `哈希清单.csv` 是论文提交包的清单，路径按 `问题一/问题二/问题三/问题四` 命名；本仓库中对应快照的清单是 `结果/标准档_20261114/哈希清单.csv`，路径按功能目录命名。两者对应同一标准档快照，但目录组织不同；本仓库的清单按功能目录命名，文件集更完整。
2. 本目录不包含代码、DEM、参数文件或标准档快照；这些在仓库的 `源代码/`、`数据/`、`结果/标准档_20261114/` 中。
3. `六方案_通信保障与可行性检验.md` 中明确记录了逐位姿采样（`全采样复核=True`，29 个缺口 / 2262 个位姿点）；它是附录 D.3 "full per-pose link sampling" 的记录依据。
